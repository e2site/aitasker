# AGENTS.md

## Правила для AI-агента

1. Одна ответственность на файл:
каждый файл должен решать только одну задачу.
Имя файла должно прямо и однозначно описывать его назначение.

2. Комментарий в начале файла:
в первых строках файла должен быть комментарий с описанием на русском языке:
- для чего предназначен файл;
- что в этот файл не входит.
При любых изменениях файла этот комментарий нужно поддерживать в актуальном состоянии.

3. Переиспользование UI:
перед тем как создавать UI-компонент или примитив с нуля, нужно проверить,
нет ли уже готового решения в `shadcn/ui`.
Если подходящий компонент в `shadcn/ui` есть, сначала использовать или расширять его,
а не писать новый с нуля.
