# AITasker

> **Статус:** публичная alpha. API MCP и формат данных могут меняться без предупреждения.

AITasker — локальное десктоп-приложение для управления проектами, задачами и планами, которое работает в связке с любым AI-агентом (Claude Code, Codex, Cursor) через [MCP](https://modelcontextprotocol.io). Приложение хранит контекст работы и отдаёт его агенту через MCP-tools, а агент планирует, реализует и фиксирует решения обратно в AITasker.

Всё работает локально: SQLite + LanceDB + локальная ONNX embedding-модель. Никаких облачных API-ключей и внешних сервисов для базовой работы не требуется — LLM вызывает только ваш агент.

## Зачем это нужно

Если вы работаете с AI-агентами и сталкивались с тем, что:

- агент забывает контекст между сессиями
- приходится каждый раз пересказывать одно и то же про проект
- наработки и инсайты теряются между задачами
- разные агенты (Claude / Codex / Cursor) не делятся знаниями

— AITasker даёт общий слой памяти и постановки задач: проекты, задачи, планы, обсуждение, подсказки-инсайты. Любой MCP-совместимый клиент подключается к локальному серверу и видит одно и то же состояние.

## Ключевые возможности

- **Проекты, задачи, планы.** Иерархия проект → задача → Markdown-план с критериями приёмки и открытыми вопросами.
- **Обсуждение по задаче.** Расширения, доработки, ответы на вопросы — без раздувания основного плана.
- **Подсказки проекта (hints).** Агент сохраняет важные инсайты по итогам задач и находит их перед новой работой через семантический поиск (локальные эмбеддинги, без облака).
- **MCP-сервер.** Полный набор tools для агента: активация проекта, поиск задач, чтение/сохранение плана, переписка, статусы, ресурсы.
- **Ручное редактирование.** Любой план можно править в UI — агент работает с актуальным состоянием.
- **Мультипроект.** Один MCP-эндпоинт обслуживает все проекты; активный проект переключается агентом.
- **Полностью локально.** SQLite, LanceDB и ONNX-модель — на вашем диске. Никаких внешних запросов.

## Установка

### Готовый установщик (рекомендуется)

Скачайте `.exe` со страницы [Releases](../../releases) и установите.

После установки запустите AITasker — он сразу поднимет локальный MCP-сервер на `http://127.0.0.1:39291/mcp`.

### Из исходников

```powershell
git clone https://github.com/e2site/aitasker.git
cd aitasker
git lfs pull
npm install
npm run dev
```

Требования:
- Windows 10/11
- Node.js 20+
- npm
- Git LFS (для папки `embeddings/` с ONNX-моделью)

`npm run dev` поднимает Vite, Electron и MCP-сервер одновременно.

## Подключение к AI-агенту

Сначала запустите AITasker. Затем добавьте сервер в свой MCP-клиент:

### Claude Code

```powershell
claude mcp add --transport http aitasker http://127.0.0.1:39291/mcp
```

Проверка:

```powershell
claude mcp list
```

### Codex

```powershell
codex mcp add aitasker --url http://127.0.0.1:39291/mcp
```

### Другой клиент

Любой MCP-клиент с поддержкой HTTP-транспорта подойдёт. Эндпоинт по умолчанию:

```text
http://127.0.0.1:39291/mcp
```

Сменить порт:

```powershell
$env:AITASKER_MCP_PORT="39300"
npm run dev
```

## Как использовать

1. Создайте проект и заполните карточку (путь к репозиторию, языки, ссылка на `SKILL.md`).
2. Создайте задачу — вручную в UI или через агента (`create_task`).
3. Попросите агента её распланировать. Например, в Claude Code:

   ```text
   Распланируй задачу "Сделать onboarding экран" в aitasker и сохрани план обратно через MCP.
   ```

4. Агент через MCP читает контекст, ищет релевантные подсказки проекта, формирует Markdown-план и сохраняет его.
5. По ходу реализации агент фиксирует расширения, доработки и важные инсайты в подсказки проекта.
6. В следующей задаче эти инсайты автоматически найдутся через `search_project_hints`.

## Дорожная карта

Альфа фокусируется на одиночной локальной работе на Windows. На очереди:

- macOS / Linux сборки
- синхронизация между устройствами
- импорт/экспорт проектов
- расширенная аналитика по задачам
- интеграции со сторонними трекерами

## Сборка Windows-приложения из исходников

```powershell
npm run dist:win
```

Артефакты появятся в `release/`:

- `release/AITasker Setup <version>.exe` — установщик
- `release/win-unpacked/` — распакованная сборка для отладки

## Типовые проблемы

**`better-sqlite3` или `NODE_MODULE_VERSION`.** Пересоберите native-модуль:

```powershell
npm run rebuild:native
```

**Не поднимается MCP endpoint.** Порт `39291` занят — переопределите через `AITASKER_MCP_PORT`.

**Папка `embeddings/` пустая.** Не подтянулись LFS-файлы — выполните `git lfs pull`.
